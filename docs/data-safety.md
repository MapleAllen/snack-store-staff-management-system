# 数据安全说明

## 数据范围

系统只保存工资管理所需的匿名成员代号、门店归属、考勤、薪资组件、调整记录、月结快照与最小化审计事件。不得录入姓名、联系方式、身份证件、住址、银行卡、自由文本备注或其他个人可识别信息。

## 本地存储与备份

Web 开发预览使用浏览器本地存储。Windows 桌面版使用本地工作区文件，并支持手动 JSON 备份及自动恢复点。数据未加密，应使用受保护的 Windows 账户、磁盘加密和独立备份介质。

## 历史兼容

旧备份可以导入，避免在版本收敛中丢失数据。旧版本的非工资业务字段不会出现在界面、参与工资计算或影响门店归档；仅保留其原始字段以支持安全迁移和备份回退。

## 审计与月结

审计时间线只记录门店、成员代号、操作类型和时间，不复制金额或备注。已月结工资使用冻结快照；解锁必须选择并记录原因。
