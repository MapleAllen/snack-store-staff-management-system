# 数据安全说明

## 数据范围

系统保存工资管理所需的员工姓名与联系方式（手机号、工号、岗位、入职日期）、门店归属、考勤、薪资组件、调整记录、月结快照与审计事件。数据只保存在本地，不接入云同步；不收集身份证件、住址、银行卡号或其他超出工资管理范围的个人数据。

## 本地存储与备份

Web 开发预览使用浏览器本地存储。Windows 桌面版使用本地工作区文件，并支持手动 JSON 备份及自动恢复点。数据未加密，应使用受保护的 Windows 账户、磁盘加密和独立备份介质。

## 历史兼容

旧备份可以导入，避免在版本收敛中丢失数据。旧版本的非工资业务字段不会出现在界面、参与工资计算或影响门店归档；仅保留其原始字段以支持安全迁移和备份回退。旧工作区中无姓名的成员会保留原有展示名，可手动编辑为真实姓名。

## 审计与月结

审计时间线记录门店、员工姓名、操作类型和时间，不复制金额或备注。已月结工资使用冻结快照；解锁必须选择并记录原因。

## 更新检查

桌面版启动时会请求 GitHub Releases API 检查最新版本，仅发送应用当前版本号与网络地址，不上传任何工资或员工数据。发现新版本后由用户手动下载安装包，应用不做静默安装。
