# 门店工资助手

门店工资助手是一个本地优先的员工工资管理应用，服务于小型、多门店的工资核对与月结工作。它不包含商品、销售、采购、库存或经营日结功能。

## 核心能力

- 使用系统生成的匿名成员代号，不录入姓名、电话、证件、地址或银行卡等个人信息。
- 管理门店、员工在职状态和按月份生效的跨店调动。
- 记录考勤、请假和薪资调整，薪资组件只能通过调整记录变更。
- 按门店逐位确认员工工资；未配置薪资、输入错误或未确认会阻止月结。
- 区分预计、已确认和已月结金额；月结后保存冻结快照，解锁必须记录原因。
- 提供门店月度汇总与近六个月已确认工资趋势。
- 支持 JSON 手动备份；桌面版在启动、恢复前和月结后创建本地恢复点。

旧版本地备份中的非工资字段可以继续导入，以避免数据丢失，但不会在当前界面展示或参与工资规则。

## 本地开发

需要 Node.js 22.12 或更高版本。

```bash
npm ci
npm run dev
npm run check
```

桌面开发模式：

```bash
npm run electron:dev
```

数据保存在本地且未加密；请使用受保护的 Windows 账户和独立备份介质。项目目前只发布源代码，尚未提供签名 Windows 安装渠道。
